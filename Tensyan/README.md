# Tensyan 班级积分工具

一个参考希沃「班级优化大师」交互体验的班级积分软件：学生卡片墙、一键加减分、积分排行、加分记录、数据统计，支持 **访客只读 / 成员仅加分 / 管理员全部** 三种权限与 **注册登录**，并支持 **制作登录U盘** 免密登录。

- 平台：Windows 10 / 11
- 技术：C# + .NET 8 WinForms（自绘 **Fluent（WinUI / Windows 11）风格** 界面，零第三方依赖）
- 显示：支持 100% / 125% / 150% 等 DPI 缩放（几何与字体一起缩放）
- 数据：保存在程序目录（绿色便携），U盘只保存登录信息

## 一、快速开始

交付包里有两种用法（功能完全一样，数据格式也一样）：

1. **安装版（推荐）**：双击 `dist\TensyanSetup.exe`
   - 当前用户安装，**不需要管理员权限**；
   - **自带 .NET 运行库**（安装包约 58 MB），目标电脑无需任何前置组件；
   - 默认装到 `%LOCALAPPDATA%\Programs\Tensyan`，创建桌面 / 开始菜单快捷方式，
     并在「设置 → 应用」里登记，可正常卸载（卸载默认保留班级数据）；
   - 静默部署：`TensyanSetup.exe --silent --dir "D:\Tensyan" --no-launch`。
2. **便携版**：运行 `dist\Tensyan\Tensyan.exe`（整个文件夹一起拷）。需要目标电脑已装
   .NET 8 Desktop Runtime。同目录的 `Tensyan.dll` / `Tensyan.deps.json` /
   `Tensyan.runtimeconfig.json` 是运行所需文件，不能只拷 exe。
   （工程目录里现在也只剩这一个便携版 exe：编译产物 bin/obj 已清理，需要重新编译时 `dotnet build` 会再生成。）
2. **首次运行会弹出「首次使用 · 创建管理员账号」向导**：填学校抬头（可空）、管理员用户名、密码，
   点「创建并进入」即可直接进入系统。程序不再预置任何默认账号，因此不需要记默认密码。
3. 之后登录有三种方式（登录窗口顶部三个标签页）：
   - **账号密码**：输入用户名与密码；
   - **U盘登录**：插入已制作的登录U盘，点「U盘登录」；
   - **注册新账号**：填用户名 / 显示名称 / 密码，点「注册并登录」（注册出来的是**成员权限**）。
   登录窗口下方会列出本机已有账号，点一下即可填入用户名。
4. 不想登录也可以：点「访客进入（只读）」。
5. 想先看效果：`Tensyan.exe --demo` 会载入两个示例班级。

> 运行环境：需已安装 **.NET 8 Desktop Runtime**。若提示缺少运行库，安装 “.NET Desktop Runtime 8” 即可。

## 二、三种登录模式与注册

| 模式 | 进入方式 | 权限 |
| --- | --- | --- |
| **访客模式** | 登录页点「访客进入（只读）」，无需账号 | 只能看学生积分、排行、加分记录、数据统计；卡片显示“只读”，不能修改任何数据 |
| **成员模式** | 账号密码 / 登录U盘 / 自行注册 | **仅加分**：可以给学生加分，不能扣分、不能管理班级与学生，看不到账号/设置/U盘页面 |
| **管理员模式** | 首次创建或由管理员分配 | 全部权限：加减分、撤销、批量/全班操作、班级与学生管理、账号权限、登录U盘、导出 Excel、备份与恢复 |

- **注册**：登录页「注册新账号」标签 → 用户名（**至少 2 个字符**，支持中文名如“张三”）/ 显示名称 / 密码 → 注册并登录（成员权限）。
  用户名唯一性、字符集、密码长度都在提交时校验；注册信息写入 `accounts.json`。
- **首次创建管理员不需要 U 盘**：本机还没有管理员账号时，注册页会自动变成「**创建管理员账号**」，
  右上角按钮直接创建管理员，不要求任何 U 盘（否则谁都没法建出第一个管理员）。
  只有**本机已有管理员**时，别人注册成员账号才需要管理员登录U盘认证（可在「系统设置 → 偏好设置」里关闭该要求）。
- **响应性**：口令校验/派生（PBKDF2 约 130ms）全部在后台线程完成，按钮立即显示「登录中…／注册中…」；
  另设 6 秒兜底超时，任何异常都会恢复按钮并给出提示，不会把窗口留在处理中状态。
- **权限收口**：访问权限在登录时确定并贯穿所有界面；成员即使触发扣分入口也会被拒绝；
  删除账号、删除班级等危险操作都有二次确认；至少保留一个管理员账号。
- **成员可见班级**：管理员可在「账号权限」里限定某个成员只看到自己任教的班级。
- 管理员可重置密码、停用账号、修改角色；登录页与「关于」里都能看到账号说明。

## 三、登录U盘

**制作**（管理员，两个入口）：「登录U盘」页，或登录界面「制作登录U盘」（会先做管理员二次验证）。
流程：选择目标U盘 → 绑定账号 → 可设口令 → 有效期（永久/7/30/90/180 天）→ 写入。

**使用**：插上U盘 → 登录页「U盘登录」标签 → 点「U盘登录」；设过口令的会要求输入口令。
登录页会主动提示“已检测到登录U盘（账号/角色/有效期）”。

**用于注册认证**：**已有管理员**时，注册成员账号前需要插入管理员登录U盘并点「U盘认证」；
程序会校验签名、口令、有效期，并确认该 U 盘绑定的是**管理员**账号（成员/访客的钥匙不能用于认证）。
本机还没有管理员时不需要认证，可直接创建管理员。

**安全设计**：

- U盘根目录写入隐藏文件 `TensyanKey.tky`（JSON + HMAC-SHA256 签名）；
- 签名密钥来自本程序数据目录的安装标识，复制、改名、手改文件都会校验失败；
- 口令用 PBKDF2-SHA256 派生存储，不保存明文；
- 支持有效期，到期自动失效；
- 密钥与本份 Tensyan 数据配套（安装标识），换电脑或换数据目录需重新制作；
- U盘只存放登录信息，班级数据仍保存在本机。

## 四、界面（Fluent）

- **配色**：浅色 Mica 底（#F3F3F3）、白色卡片 + 1px 描边（#E5E5E5）、Windows 11 强调色（#005FB8），
  语义色：加分绿 #0F7B0F、扣分红 #C42B1C、提示橙 #9D5D00；去掉了旧版的重阴影与渐变。
- **字体**：Segoe UI Variable Text → Segoe UI → Microsoft YaHei UI 自动回退；统一 Fluent 字号体系
  （Caption 12px / Body 14px / BodyStrong 14px 半粗 / Subtitle 16px / Title 20px / Display 27px）。
- **控件**：Fluent 按钮（强调色实心 / 标准描边 / Subtle 三种形态）、NavigationView 风格左导航
  （选中项圆角底 + 强调色指示条）、Fluent 下拉选择（自绘，替代系统 ComboBox）、圆角输入框（聚焦变强调色）、
  分段控件标签页、InfoBar 风格提示条、Fluent 卡片与列表。
- **窗口**：自绘标题栏、Win11 圆角窗口（DWM）、无边框可缩放。
- **动效**：内置一个共享计时器驱动的补间引擎（`UI/Anim.cs`，约 66fps，统一缓动函数），所有动画可一键关闭：
  - 学生卡片：加分时分数平滑滚动到新值 + 头像轻微弹起 + 描边高亮渐隐；
  - 飘字：`+N / -N` 上浮 + 轻微横移 + 弹出缩放（`EaseOutBack`）+ 淡出；
  - 提示条：从下方淡入上滑、停留后淡出上移（整个卡片带透明度绘制，不再硬切）；
  - 随机点名：换人频率由快到慢（`EaseOutCubic` 减速），中奖者弹出并以头像高亮环收尾；
  - 页面：切换时内容轻微右滑入场；对话框与登录窗：淡入 + 上移 18px；
  - 窗口级：只有一个主窗口，启动即淡入；点关闭时淡出下沉再真正关闭；
  - 登录不是第二个窗体：登录/注册是主窗口里的一个状态，登录成功后左侧栏从 396px 动画收窄到 212px、
    内容区换成主界面（因此不存在“两个主体”、也不需要预建窗体再隐藏登录窗这类切换技巧）；
    「退出登录」只是把同一个窗口切回登录状态。
  - 按钮与导航项：悬停底色/文字颜色 130–150ms 渐变过渡，不再瞬间跳变；
  - 登录：口令校验与口令派生（PBKDF2，约 130ms）都在后台线程，按钮立刻显示「登录中…」；
    主窗口先在登录窗后面构建并绘制完成，再收起登录窗，进入主界面没有桌面空档。
- **登录耗时自检**：`Tensyan.exe --logintest <目录>` 会输出逐项耗时（点击 → 校验 → 主窗口构建 → 上屏 → 登录窗收起）。
- **DPI 缩放**：所有几何常量按 96 DPI 设计，运行时经 `Theme.P()` 换算；字号用磅值由 GDI 随 DPI 放大，
  两者比例一致。窗口若大于屏幕会自动收窄（`ChromeForm.FitToScreen`）。
  可用环境变量 `TENSYAN_SCALE=1.25` 强制缩放做自检。截图自检默认关闭动画（`TENSYAN_SHOT_ANIM=1` 可保留）。

## 五、功能一览

**学生积分页**：卡片墙（头像按姓名生成、颜色随积分变化）、悬停显示绿色「+」红色「−」快速加减分、
点卡片打开加减分窗口、右键菜单（加分/扣分/详情/编辑/归档/删除）、搜索与排序、批量选择加减分、全班加分。

**加减分窗口**：加分/扣分切换、快捷分值（1/2/3/5，可自定义）、理由标签（可增删改）、备注、实时预览“即将加 N 分 → 结果”。

**积分排行**：前三名领奖台 + 完整榜单（名次、头像、进度条、分数），支持总积分 / 本周 / 本月 / 今日排行。

**加分记录**：按时间范围、类型、学生筛选，显示操作人与身份，底部统计加/扣/净变化，一键导出 Excel。

**数据统计**：学生总数、班级总积分、今日加分、人均积分；近14天每日加减分趋势；加分理由分布；积分段分布。

**账号权限**：新增/编辑账号、重置密码、停用启用、删除；角色说明；成员可见班级限定；修改自己的密码。

**系统设置**：班级管理（新建/编辑/删除/设为当前）、批量添加学生、导出学生名单、恢复归档学生、
理由标签管理、快捷分值、音效与动画开关、备份保留份数、载入示例数据、立即备份/从备份恢复、
导出当前班级积分榜/全部班级总表/全部积分记录、清零班级积分、清空全部记录。

**其他**：随机点名（滚动抽取，可直接加 1/2 分）、撤销上一步（管理员）、加分浮动动画与提示音、
Excel 导出（自写 XLSX，无需 Office 组件）、自动备份（保留最近 N 份）。

## 六、数据与文件位置

| 内容 | 位置 |
| --- | --- |
| 班级 / 学生 / 积分记录 / 设置 | `data\classdata.json` |
| 账号、角色、密码哈希 | `data\accounts.json` |
| 安装标识与签名密钥 | `data\install.json` |
| 自动备份 | `data\backups\classdata-*.json` |
| 运行日志 | `data\tensyan.log` |

数据放在哪里，按下面的顺序决定（**每一步都会验证“能不能真的写进去”**）：

1. `--data <目录>` 或环境变量 `TENSYAN_DATA`（不可写时自动跳过并提示）；
2. `data-location.txt` 记录的自定义位置（程序目录旁，找不到就找 `%APPDATA%\Tensyan\data-location.txt`），
   由「**系统设置 → 数据与备份 → 更改数据位置…**」写入：会把现有数据复制过去、记住新位置、提示重启；
3. **exe 同级的 `data\`**（绿色便携，整体拷走即迁移）；
4. 程序目录不可写（Program Files、只读盘）→ `%APPDATA%\Tensyan`；
5. 连用户目录也写不了 → `%TEMP%\Tensyan`（能用但不保证持久），并在界面弹黄色提示 + 记日志。

### 关于“哪里都写不了”

早先的实现用“**写一个探针文件再删掉**”判断可写性，且目标文件不存在时用 `File.Move` 落盘。
在**禁止删除/改名**的受管环境（部分杀软、组策略、只读还原卡、容器沙箱）里这会连环失败：
探针删除失败 → 判为不可写 → 回退到同样不能删的目录 → 首次保存 `File.Move` 抛异常且只写进日志，
表现出来就是“哪儿都写不进去、数据保存不了”。现在改为：

- **只要能创建并写入就算可写**，删除失败只记一条提示；
- `WriteAtomic` 逐级降级：`File.Replace` → `File.Copy` 覆盖 → **直接写目标文件**（只需创建/写入权限）；
- `Store.LastSaveError` 记录失败原因，主界面**红色提示**（不再静默）；
- 启动时若数据目录被降级/兜底，弹黄色提示说明原因（`Paths.WarningReason`）；
- 用户可随时在设置里**换一个可写位置**。

## 七、开发与自检

```powershell
# 编译
dotnet build Tensyan.csproj -c Release

# 载入示例数据运行
bin\Release\net8.0-windows\Tensyan.exe --demo

# 生成全部界面截图（含三种模式对比、注册向导、各弹窗）
Tensyan.exe --shot .\_shots --data .\_shotdata --demo

# 按 125% / 150% 缩放生成截图，检查高 DPI 下的排版
$env:TENSYAN_SCALE='1.25'; Tensyan.exe --shot .\_shots125 --data .\_data125 --demo

# 运行自检：U盘密钥签名/口令/有效期/异机识别、磁盘枚举、Excel 导出、密码校验

# 登录/注册耗时自检：点击 → 校验 → 主窗口构建 → 上屏 → 登录窗收起；并覆盖注册与U盘认证闸门

# 界面功能自检：按身份验证“能否添加学生”（store → 界面卡片）等
Tensyan.exe --uitest .\_uitest
```

## 八、账号说明

程序**不预置任何账号**：

- 首次运行 → 「首次使用 · 创建管理员账号」向导，创建的第一个账号即管理员（**不需要 U 盘**）；
- 之后可在登录页「注册新账号」自助注册成员账号（已有管理员时需管理员U盘认证），
  或由管理员在「账号权限」里新增任意角色的账号；
- 忘记管理员密码时，删除 `data\accounts.json` 后重启程序，会重新进入创建向导（班级与积分数据不受影响）。

### 常见疑问：为什么添加不了学生？

「添加 / 编辑 / 删除学生」「批量导入」「系统设置」这些都属于管理功能，**只有管理员身份可用**：

- **成员（仅加分）**：能加分、能用全班加分，但学生卡片只能看到加分按钮；
  右上角「添加学生」会显示锁图标，点击或看副标题会明确提示“添加 / 修改学生需要管理员账号”。
- **访客（只读）**：所有修改入口都不可用。
- 需要让某人管理学生时：用管理员账号在「账号权限」里把该账号角色改成**管理员**，或直接用管理员账号登录。
- 另外搜索框里残留的关键字会把新加的学生过滤掉，添加成功后程序会自动清空搜索框。

## 九、窗口结构（为什么只有一个窗体）

```
MainForm（唯一顶层窗口，Application.Run 的宿主）
├─ 标题栏（自绘，随状态切换标题）
├─ 左侧栏：登录态 396px ↔ 主界面态 212px（宽度动画过渡）
│    ├─ 登录态：品牌 logo + 标语 + 三种模式说明 + 署名
│    └─ 主界面态：logo + 导航项（按角色显示）+ 当前身份卡片（退出登录）
├─ 顶栏（仅主界面态）：班级选择 · 班级概况 · 模式徽标 … 撤销 / 随机点名
└─ 内容区
     ├─ LoginView（登录 / U盘登录 / 注册，Panel，不是窗体）
     └─ 各功能页面（按需创建）
```

- 登录成功 = `MainForm.ShowMain(session)`：设置会话 → 应用权限 → 加载页面 → 左侧栏动画收窄，全程同一个窗口。
- 退出登录 = `MainForm.ShowLogin()`：切回登录状态，窗口不关闭、不重建。
- 只有「首次创建管理员向导」「加减分」「账号编辑」等是真正的模态对话框（它们本来就应该盖在主窗口上）。
- 因此不存在两个顶层窗体互相“挂”的问题，也不会出现切换时的桌面空档。
- **启动与关闭不做窗口透明度动画**：透明度会把窗口变成分层窗口，恢复时会引起重绘闪一下、
  也会丢掉 Win11 圆角，所以打开只用轻微上滑、关闭直接关闭；界面内部的动效（页面滑入、
  卡片、飘字、提示条、悬停）不受影响。
- 启动过程会写进 `data\tensyan.log`（启动参数 → 创建主窗口 → 进入消息循环 → 主窗口已显示：
  登录/主界面 → 退出），排查“窗口没出来”时先看这个日志。
- 数据文件（classdata.json / accounts.json）**无法解析时不会被覆盖**：会先备份成
  `data\backups\*.broken-<时间>.json`，界面弹提示，再按空数据启动。

## 十、安装程序（打包）

### 产物

| 文件 | 说明 |
| --- | --- |
| `dist\TensyanSetup.exe` | **需要管理员**（清单 `requireAdministrator`）：UAC 提权后不受受限令牌/沙箱影响，默认装到 `C:\Program Files\Tensyan`，卸载信息写 HKLM，装完把安装目录的修改权限授予当前用户 |
| `dist\TensyanSetup-标准用户版.exe` | `asInvoker`：免 UAC，默认装到 `%LOCALAPPDATA%\Programs\Tensyan`，卸载信息写 HKCU |
| `dist\Tensyan\` | 便携版（约 0.2 MB，需目标机已装 .NET 8 桌面运行时） |

两个安装包都自带 .NET 运行库（各约 58 MB），目标电脑无需任何前置组件。

### 为什么“强制管理员”是关键

沙箱/受限环境（例如某些工具代跑程序、低完整性令牌、AppContainer）会把可写范围限制在
自己的工作目录，于是**任何盘都报没有权限**。`requireAdministrator` 触发 UAC 后得到的是
完整管理员令牌，可写范围不再受限 —— 实测在本机（账号本属管理员组，但会话被降为
Low 完整性令牌）：

```
强制管理员版 --silent --dir D:\App\Tensyan  →  exit=0，10 个文件就位
注册表：HKLM 已登记（InstallLocation=D:\App\Tensyan，所有用户可见）
数据：D:\App\Tensyan\data\{classdata,accounts,install}.json（便携=True）
ACL：PC-20260827FQJH\ThinkPad:(OI)(CI)(M)  ← 自动授权，之后普通身份也能写数据
程序启动：主窗口已显示：登录界面
```

卸载器在需要时（装在 Program Files / 有 HKLM 登记）会**自动请求管理员权限**重跑一遍。
安装界面还提供 **[诊断]**：分别探测临时目录、用户目录、目标目录并给出结论，
可直接复制发回定位问题。

### 构建

```powershell
# 标准安装包（自包含负载，目标机免运行库）
powershell -ExecutionPolicy Bypass -File build-installer.ps1

# 精简包（负载不含运行库，约 1 MB；要求目标机已装 .NET 8 桌面运行时）
powershell -ExecutionPolicy Bypass -File build-installer.ps1 -FrameworkDependent
```

脚本做四件事：① `dotnet publish` 主程序（自包含单文件）→ ② 打成 `payload.zip`
→ ③ 编译卸载器 → ④ 用 `-p:PayloadZip/-p:UninstallerSource` 把负载与卸载器嵌入安装程序，
输出到 `dist\`。全程离线（运行时包在本地 NuGet 缓存里）。

### 组成

| 路径 | 作用 |
| --- | --- |
| `Installer\TensyanSetup\` | 安装界面（Fluent 无边框窗口）+ 内嵌负载 + `--silent/--shot` 等参数 |
| `Installer\TensyanUninstall\` | 独立的小卸载器（约 50 KB），注册表 UninstallString 指向它 |
| `Installer\Shared\InstallCore.cs` | 安装/卸载核心：解压、快捷方式、注册表、自删除 |
| `Installer\Shared\SetupUi.cs` | 安装程序专用 Fluent 控件（按钮、细进度条、无边框外壳） |

### 安装做了什么

1. 校验目标目录可写（默认 `%LOCALAPPDATA%\Programs\Tensyan`，不需要管理员）；
2. 解压负载到目标目录，写入 `TensyanUninstall.exe`；
3. 创建桌面 / 开始菜单快捷方式（含“卸载 Tensyan”），用 `WScript.Shell` 生成 `.lnk`；
4. 写 `HKCU\...\Uninstall\Tensyan`（显示名、版本、发布者 Clarusvita Studio、图标、
   安装位置、卸载命令、QuietUninstallString、EstimatedSize…）；**写不进去也不影响安装**，
   会记日志并在界面提示，仍可用开始菜单里的卸载快捷方式；
5. 可选安装完成后启动。

### 卸载

删除程序文件与快捷方式、移除注册表项；**默认保留 `data` 文件夹**（班级数据），
勾选“同时删除班级数据”才删。目录清空后由 `cmd` 延时自删除，不留残渣。

### 为什么没有 msi / msix

- 这台机器没有 WiX / Inno Setup / NSIS，也没有 Windows SDK（`makeappx`、`signtool` 都缺失），
  离线环境下无法产出 msi/msix；
- msix 还要求用受信任的代码签名证书签名（否则目标机默认装不上，需要开开发者模式并信任证书）；
- exe 安装包最通用：双击即装、免运行库、免管理员。需要 msi/msix 时告诉我，
  在能联网/有 SDK 的机器上补即可（源码与脚本都已就绪）。

### 自检结果（在沙箱里实测）

| 项 | 结果 |
| --- | --- |
| 静默安装 `--silent --dir … --no-launch` | 退出码 0，9 个文件就位 |
| 快捷方式 | 3 个 `.lnk` 生成成功，文件头 `4C 00 00 00`，内含 `Tensyan.exe` 目标路径 |
| 安装后启动 | 进程存活，日志出现“主窗口已显示：登录界面” |
| 卸载（保留数据） | 退出码 0，程序文件与快捷方式删除，`data\accounts.json` 保留 |
| 重装 + 彻底卸载 | 退出码 0，安装目录被完全删除 |
| 注册表 | 本沙箱禁止写 HKCU（`UnauthorizedAccessException`），已按“非致命”处理并在日志记录；普通用户会话下正常写入 |

## 配对手机与后台常驻（2026-10-05）

桌面端新增三类能力，与手机端（Java 版 v1.2）配套：

| 能力 | 说明 |
| --- | --- |
| **配对手机** | 侧栏「配对手机」页显示 6 位配对码（2 分钟有效）；手机在「同步」页输入即完成配对 |
| **配对后自动登录** | 配对时电脑发一张长期令牌给手机；之后手机打开就用那张令牌换取身份（管理员/成员），**不需要在手机上输账号密码** |
| **局域网同步** | 同一 Wi-Fi 下双向合并数据：事件按 Id 取并集（幂等、永不冲突）、撤销用"或"合并、分数按事件重算 |
| **托盘常驻** | 关闭窗口只是**收进托盘**（后台继续等手机连接）；双击托盘恢复窗口，右键托盘 → 退出 才真正结束 |
| **Fluent 统一** | 图标字体优先使用 Windows 11 自带的 **Segoe Fluent Icons**（旧系统退回 MDL2）；配色/圆角/字号与手机端共用同一套 Fluent 令牌（#005FB8 / #F3F3F3 / #E5E5E5 …） |

### 手机连不上电脑时

1. 确认电脑端 Tensyan **正在运行**（可在托盘中，关窗口不等于退出）；
2. 手机与电脑连**同一个 Wi-Fi**（或电脑开热点给手机）；
3. Windows 防火墙放行：**TCP 47653**（同步与配对）、**UDP 47654**（让手机自动找到电脑）；
4. 电脑上还有多张网卡（虚拟机/热点）时，手机可能找到多个地址，换一个试即可。
