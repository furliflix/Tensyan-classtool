# Tensyan 代码签名说明

> 目标：解决 Windows 的「未知发布者」「SmartScreen 已阻止」「杀软报毒」问题。
> 本文说明**已经做了什么**、**自签名能解决到什么程度**、以及**真正解决要怎么办**。

---

## 一、已经做的（全部产物已签名）

用一张**自签名代码签名证书**（CN=Clarusvita Studio, O=Clarusvita Studio, C=CN，有效期至 2031-10-05）
对三个版本的全部产物签了名，并用 `Get-AuthenticodeSignature` 校验为 **Valid**：

| 产物 | 说明 | 签名 |
| --- | --- | --- |
| `TensyanSetup.exe` / `TensyanSetup-标准用户版.exe` | 64 位版安装程序（自带运行库，58 MB） | ✅ Valid |
| `TensyanSetup-lite.exe` / `TensyanSetup-标准用户版-lite.exe` | 64 位**精简版**（559 KB，需目标机装 .NET 8） | ✅ Valid |
| `TensyanSetup-x86.exe` / `TensyanSetup-x86-标准用户版.exe` | 32 位版安装程序（440 KB，需 .NET Framework 4.8） | ✅ Valid |
| `TensyanSetup-XP.exe` | XP 特别版安装程序（628 KB，需 .NET Framework 3.5） | ✅ Valid |
| `Tensyan.exe` / `TensyanX86.exe` / `TensyanXP.exe` | 绿色版程序本体 | ✅ Valid |
| 安装包**内嵌**的 `Tensyan.exe` 与 `TensyanUninstall.exe` | 已实测：装出来就是签名版 | ✅ Valid |

> 签名顺序很关键：**先签程序本体 → 再打进安装包 → 最后签安装包**。

## 二、必须说清的三件事（否则你会以为"签了名就没事了"）

1. **自签名 ≠ 对别人的电脑不再提示「未知发布者」**
   只有当目标电脑**把我们的证书装进「受信任的根证书颁发机构」**时，签名才被信任、才会显示发布者名字。
   没装证书的电脑看到的仍然是「未知发布者」——甚至可能显示"签名无效"。
2. **自签名 ≈ 对杀软误报几乎没有帮助**
   杀软报毒看的是**启发式特征 + 文件信誉**（下载量、签名者信誉、是否加壳/自解压等），
   自签名不会给它加分；某些引擎反而会因为"未受信任的签名"而警觉。
3. **真正解决要靠 CA 签发的代码签名证书**
   - **OV 代码签名证书**（约 ¥1000–3000/年）：需要企业/个人实名验证；签名后 SmartScreen 仍需**积累信誉**（一段时间/一定下载量后才不再拦）。
   - **EV 代码签名证书**（更贵，需硬件令牌）：**立刻**获得 SmartScreen 信誉，新发布的程序也不会被拦——这是"发出去就能装"的唯一捷径。
   - 无论哪种，签名都**必须带时间戳**（脚本已默认使用 DigiCert 时间戳服务），这样证书过期后旧版本签名依然有效。

## 三、如果你想用现在这张自签名证书（内网 / 自用机器）

证书文件在 `..\Tensyan-codesign\`：

| 文件 | 用途 |
| --- | --- |
| `Tensyan-CodeSign.cer` | **公钥**，发给要安装的电脑，装进"受信任的根 + 受信任的发布者" |
| `Tensyan-CodeSign.pfx` | 私钥（口令 `TensyanSign2026`）—— **妥善保管，这是你的签名身份** |

在目标电脑上信任（普通用户即可，无需管理员）：

```powershell
Import-Certificate -FilePath .\Tensyan-CodeSign.cer -CertStoreLocation Cert:\CurrentUser\Root
Import-Certificate -FilePath .\Tensyan-CodeSign.cer -CertStoreLocation Cert:\CurrentUser\TrustedPublisher
```

或图形操作：双击 `Tensyan-CodeSign.cer` → 安装证书 → 本地计算机/当前用户 →
「受信任的根证书颁发机构」→ 完成（再重复一次选「受信任的发布者」）。

如果学校/公司有域环境，可以让管理员用组策略把这张证书分发到所有机器，那样内网就没有"未知发布者"提示了。

## 四、换成真证书后怎么签名（一条命令）

```powershell
# 用买来的 pfx（会自动重新构建三个版本、按正确顺序签名、并打印校验表）
powershell -ExecutionPolicy Bypass -File sign-all.ps1 -Pfx .\codesign.pfx -Password 证书口令

# 或证书已导入本机证书库，按指纹签
powershell -ExecutionPolicy Bypass -File sign-all.ps1 -Thumbprint <证书指纹>

# 只对已有产物补签（不重新构建）
powershell -ExecutionPolicy Bypass -File sign-all.ps1 -Thumbprint <指纹> -SkipBuild

# 继续用自签名证书
powershell -ExecutionPolicy Bypass -File sign-all.ps1 -SelfSigned
```

需要向 CA 申请证书时，可先生成 CSR（证书签名请求）交给 CA：

```powershell
# 生成私钥 + CSR（CN 改成你的公司/个人名）
$c = New-SelfSignedCertificate -Subject 'CN=你的名称, O=你的组织, C=CN' -Type Custom `
     -KeyUsage DigitalSignature -KeyAlgorithm RSA -KeyLength 3072 `
     -CertStoreLocation Cert:\CurrentUser\My -NotAfter (Get-Date).AddYears(1)
# 然后用 certreq 基于该私钥生成 CSR（具体参数按 CA 要求填写，CA 一般会提供模板）
```

## 五、杀软误报的应对清单（这比签名更直接）

按有效性排序：

1. **把误报提交给厂商**（免费、最有效）
   - 微软：<https://www.microsoft.com/en-us/wdsi/filesubmission>（选 "Software developer" → 上传 `TensyanSetup.exe`）
   - 国内：火绒、360、腾讯电脑管家、卡巴斯基等都有"误报申诉/文件上报"入口
   - 说明里写清：这是绿色便携的班级积分工具、无网络行为、源码结构（WinForms + 本地文件读写）
2. **换用更容易被接受的打包形态**
   - ✅ 用 **精简版安装包** `TensyanSetup-lite.exe`（559 KB，**不是**自解压单文件）——"自包含单文件 58 MB"是最容易触发启发式的形状
   - ✅ 或直接发 **ZIP 绿色版**（解压即用，不经过安装器）
   - ⚠️ 避免在安装包里再套一层压缩/自解压
3. **用 EV 代码签名证书**（如果预算允许）——一次解决"未知发布者 + SmartScreen + 部分杀软信誉"
4. **保持签名者一致、持续发布**：同一个证书、同一个发布者名称，信誉会累积
5. 在说明书里写明"未联网、只读写本机文件、数据放在自己目录"，方便用户/IT 判断（本程序确实如此：无任何网络请求）

## 六、验证签名（随时可自查）

```powershell
Get-AuthenticodeSignature '.\dist\TensyanSetup.exe' |
    Format-List Status, StatusMessage, SignerCertificate
```

`Status = Valid` 且 `SignerCertificate.Subject = CN=Clarusvita Studio...` 即为已签名；
在没有信任该证书的机器上会显示 `UnknownError`（根证书不受信任）——这属于预期现象，见第二节第 1 条。
